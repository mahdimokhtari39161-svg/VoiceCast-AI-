# انتخاب موتور صدای فارسی

این انتخاب روی کیفیت فارسی، تعداد شخصیت‌های مستقل، هزینه و حریم خصوصی اثر دارد. کلید API نباید در کد فرانت‌اند یا مخزن GitHub ذخیره شود.

## گزینهٔ پیشنهادی برای اجرای چندشخصیتی

Google Cloud Gemini-TTS (مدل‌های 2.5 Flash/Pro TTS):
- مستند رسمی چندگوینده را برای مدل‌های Flash و Pro ذکر می‌کند.
- خروجی MP3 و WAV را پشتیبانی می‌کند.
- زبان Persian (Iran)، کد fa-IR، در فهرست زبان‌ها وجود دارد؛ در مستند جاری این زبان با وضعیت Preview علامت‌گذاری شده است.
- قیمت اعلام‌شده برای 2.5 Pro TTS: ورودی متن $1 و خروجی صوت $20 به‌ازای هر یک میلیون توکن؛ هر ثانیه صوت 25 توکن محاسبه می‌شود. هزینهٔ تقریبی خروجی حدود $0.03 برای هر دقیقه است، به‌علاوه هزینهٔ ورودی متن. این برآورد بر اساس قیمت منتشرشده است و قیمت/دسترسی می‌تواند تغییر کند.
- برای شروع به پروژهٔ Google Cloud، فعال‌سازی billing و اعتبارنامهٔ سرور نیاز است.

منابع رسمی:
- https://docs.cloud.google.com/text-to-speech/docs/gemini-tts
- https://ai.google.dev/gemini-api/docs/pricing
- https://cloud.google.com/text-to-speech/pricing

## گزینهٔ اقتصادی جایگزین

Azure Speech:
- دو صدای استاندارد فارسی ایران در مستند Microsoft ثبت شده‌اند: Dilara (زن) و Farid (مرد).
- طرح F0 در صفحهٔ قیمت‌گذاری Microsoft، ماهانه 500,000 نویسهٔ Neural TTS رایگان اعلام می‌کند.
- برای چند شخصیت، باید هر دیالوگ جداگانه با صدای انتخابی ساخته و سپس در برنامه به هم متصل/میکس شود؛ تنوع صدا محدودتر از موتور چندگوینده است.

منابع رسمی:
- https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support
- https://azure.microsoft.com/en-us/pricing/details/speech/

## تصمیم لازم پیش از اتصال واقعی
تا وقتی مالک پروژه روش هزینه و حساب ارائه‌دهنده را تأیید نکند، هیچ درخواست پولی ارسال نمی‌شود و هیچ کلید محرمانه‌ای درخواست یا در مخزن ثبت نمی‌شود. پس از انتخاب، موتور باید از سمت سرور فراخوانی شود و فایل‌های تولیدی در فضای ذخیره‌سازی امن/قابل دانلود نگهداری شوند.
