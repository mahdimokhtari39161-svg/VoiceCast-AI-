# VoiceCast AI

استودیوی فارسی برای طراحی، مدیریت و پیش‌نمایش سناریوهای چندگوینده‌ای؛ با مسیر آماده‌سازی وب‌اپ و بستهٔ اندروید.

## امکانات فعلی
- رابط فارسی راست‌چین و واکنش‌گرا
- ساخت چند گوینده با نام، صدای دستگاه، سرعت، زیر و بمی و بلندی مستقل
- تقسیم متن به جمله/خط یا پاراگراف و تخصیص نوبتی یا به راوی
- ویرایش، حذف، جابه‌جایی و پخش جداگانهٔ دیالوگ‌ها
- کنترل اجرا: پخش، مکث، ادامه و توقف
- مکث قابل تنظیم بین دیالوگ‌ها
- ذخیرهٔ خودکار پروژه در مرورگر
- وارد کردن و خروجی گرفتن پروژهٔ JSON و خروجی متن سناریو
- PWA و پوستهٔ آفلاین برای فایل‌های کش‌شده
- پیکربندی Capacitor و گردش خودکار ساخت APK آزمایشی اندروید

## اجرای محلی
```bash
npm install
npm run dev
```

ساخت وب:
```bash
npm run build
npm run preview
```

## ساخت APK اندروید
از زبانهٔ Actions، گردش **Build Android APK** را اجرا کن. فایل آزمایشی پس از پایان موفق، در Artifacts با نام `VoiceCast-AI-debug-apk` قرار می‌گیرد. این APK، نسخهٔ debug است و برای انتشار عمومی باید امضا و پیکربندی انتشار جداگانه انجام شود.

## وضعیت موتور صدا
پیش‌نمایش فعلی از Web Speech API سیستم‌عامل/مرورگر استفاده می‌کند؛ تعداد و کیفیت صداهای فارسی به دستگاه وابسته است. قابلیت‌های زیر هنوز به موتور صوتی واقعی و پیکربندی سرویس نیاز دارند:
- صداهای طبیعی فارسی با چند شخصیت مستقل و قابل اتکا
- تولید و دانلود MP3/WAV از دیالوگ‌ها
- هم‌خوانی هم‌زمان چند گوینده و میکس موسیقی/افکت
- تولید گروهی فایل‌ها و صف پردازش

این موارد نباید با صدای آزمایشی مرورگر اشتباه گرفته شوند. برای اتصال موتور ابری، باید ارائه‌دهنده، شرایط استفاده، هزینه و محل امن نگهداری کلید API مشخص شود. هیچ کلید محرمانه‌ای داخل کد فرانت‌اند قرار نمی‌گیرد.

## فناوری‌ها
React، TypeScript، Vite، Web Speech API، PWA و Capacitor.
