# VoiceCast AI

استودیوی موبایل‌محور برای طراحی و پیش‌نمایش اجرای چندگوینده‌ای متن فارسی.

## وضعیت فعلی

نسخهٔ اولیهٔ رابط کاربری با React و TypeScript آماده شده است. این نسخه امکان وارد کردن متن فارسی، تقسیم متن به بخش‌ها، تعریف چند نقش، انتخاب صدای موجود در دستگاه و پیش‌نمایش ترتیبی دیالوگ‌ها را فراهم می‌کند.

### امکانات نسخهٔ اولیه
- رابط فارسی و راست‌چین، سازگار با موبایل
- تقسیم متن بر اساس پاراگراف و نشانه‌های پایان جمله
- افزودن، حذف و نام‌گذاری گویندگان
- تخصیص هر بخش به گویندهٔ دلخواه
- انتخاب صداهای نصب‌شده در مرورگر و تنظیم سرعت و زیر و بمی
- ذخیرهٔ خودکار سناریو در حافظهٔ مرورگر
- وب‌اپ قابل نصب (PWA manifest)
- گردش ساخت خودکار با GitHub Actions و آماده‌سازی انتشار GitHub Pages

## اجرای محلی

```bash
npm install
npm run dev
```

برای ساخت نسخهٔ نهایی:

```bash
npm run build
npm run preview
```

## نکتهٔ مهم دربارهٔ صدا

پیش‌نمایش فعلی از Web Speech API مرورگر استفاده می‌کند. صداهای در دسترس، کیفیت تلفظ فارسی و تعداد صداهای متفاوت به سیستم‌عامل، مرورگر و بسته‌های صوتی نصب‌شده وابسته است. این نسخه تضمین نمی‌کند که همهٔ دستگاه‌ها چندین صدای فارسی داشته باشند.

هم‌خوانی هم‌زمان چند صدا، تولید فایل MP3، موسیقی پس‌زمینه و APK بومی هنوز پیاده‌سازی نشده‌اند. برای این قابلیت‌ها باید موتور TTS مناسب فارسی و زنجیرهٔ پردازش/میکس صدا اضافه شود. هیچ کلید API یا سرویس پولی در مخزن قرار داده نشده است.

## فناوری‌ها
React، TypeScript، Vite، Lucide و Web Speech API.
